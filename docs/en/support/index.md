::: tip Send a video when possible
For movement errors, drift, orientation problems or dropouts, a screen recording of the SlimeVR interface plus a video of your actual wearing usually locates the issue faster than a text description alone.
:::

## When Submitting an Issue, Please Provide

- Product package and number of trackers
- Tracker and receiver model
- Current firmware version
- Windows, SlimeVR and SteamVR versions
- Indicator-light state
- What you did before the problem appeared
- Steps that reliably reproduce the problem
- Clear photos or videos

## Recommended Description Format

```text
Problem:
Device model:
Firmware version:
System & software versions:
Reproduction steps:
Already tried:
Indicator-light state:
```

# 快速开始

本页将现有说明书中的开机流程整理为一个完整的首次使用顺序。追踪器与接收器出厂时已经完成配对，正常情况下无需重新配对。

## 使用前准备

- Neko Nya 追踪器及配套绑带
- 充电底座与接收器
- 接收器天线
- 一台可运行 SlimeVR 的电脑

::: warning 首次使用前
请先确认追踪器电量充足，并阅读[安全与充电说明](/guide/charging-controls)。
:::

## 1. 连接接收器

1. 将天线正确安装到接收器。
2. 将接收器连接到电脑 USB 接口。
3. 尽量让接收器远离大面积金属遮挡，并保持天线周围空间通畅。

**完成标志：**电脑识别到 USB 设备，启动 SlimeVR 后可以看到接收器或追踪器状态。

## 2. 开启追踪器

### 批量启动

将追踪器正确放入充电底座，按下底座左侧按钮批量开启。

### 独立启动

追踪器处于关机状态时，按下追踪器侧面的功能键即可单独开启。

## 3. 安装 SlimeVR

前往 [SlimeVR 官方网站](https://slimevr.dev/) 下载并运行软件。

::: tip 下载遇到问题
如果官方渠道暂时无法下载，可通过产品支持渠道获取经过确认的安装文件。不要从来源不明的网盘下载软件或固件。
:::

## 4. 确认设备

1. 启动 SlimeVR。
2. 确认接收器已经连接电脑。
3. 确认追踪器已经开启。
4. 等待软件自动识别已连接点位。

如果软件没有识别设备，请前往[故障排查](/support/troubleshooting#软件找不到追踪器)。

## 5. 分配、佩戴与校准

按照身体部位分配追踪器，然后参考[组装与佩戴](/guide/assembly)固定设备。正式使用前完成 SlimeVR 的身体比例设置、完整重置和佩戴校准。

**完成标志：**移动身体时，SlimeVR 中对应追踪器和骨架方向同步变化。

## 6. 批量关机

在追踪器开机状态下，按下接收器上的批量关机按钮即可关闭设备。

::: warning 接收器按钮
接收器左侧金属按钮在原始说明书中标注为 `SWO`。请以接收器实物丝印为准，避免与追踪器和充电底座的 `SW0` 按钮混淆。
:::

# 维修与寄修

本页介绍常见易损件的处理方式、寄修流程与费用说明。

## 易损件清单

| 部件 | 常见问题 | 处理建议 | 保修 |
| --- | --- | --- | --- |
| 电池 | 续航下降、鼓胀、破损 | 鼓胀/破损立即停用，联系售后更换 | 3 个月 |
| 绑带 | 松弛、断裂、魔术贴失效 | 可自行更换 | 1 个月 |
| 卡扣 | 断裂、松动 | 可自行更换 | 1 个月 |
| GoPro 胸挂 | 卡扣断裂 | 可自行更换 | 3 个月 |
| 按钮 | 失灵 | 联系售后 | 3 个月 |
| 外壳 | 破损 | 联系售后 | 3 个月 |

::: danger 电池异常立即停用
电池出现鼓胀、破损、异味、异常发热或外壳变形时，请立即停止充电和使用，并联系售后。不要自行拆解或继续使用。
:::

## 寄修流程

1. 联系[售后支持](/support/)，说明故障现象、设备型号、固件版本，并提供照片或视频。
2. 客服确认后，按指引寄回设备。
3. 维修完成后寄回。

- 寄修地址与收件信息：联系售后后由客服提供（不公开在说明书中）。

## 保修与运费

- **保修期**：自收到货起 **3 个月**。
- **绑带、卡扣等易损件**：保修 **1 个月**。
- **非人为损坏**：维修免费，寄修运费全额报销（寄修前先与售后沟通确认使用的快递）。
- **人为损坏**：自行承担寄出运费和维修费用。
- **保修期外**：维修与运费以客服报价为准。

## 自助处理

以下问题可在客服指引下自行处理：

- 更换绑带、卡扣、魔术贴
- 清洁充电触点
- 重新配对（见[新增或更换追踪器](/guide/add-tracker)）

涉及电池、主板等内部部件的故障请走寄修流程，不要自行拆机。

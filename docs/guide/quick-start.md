# 快速开始：连接与开机

本页是首次使用的第 2 步，负责把接收器与追踪器连接、开机。追踪器与接收器出厂时已经完成配对，正常情况下无需重新配对。

首次使用请按顺序完成：**确认配件 → 连接与开机 → 配置 SlimeVR → 组装与佩戴 → 首次校准**（页面底部有「下一步」引导）。

## 使用前准备

- Neko Nya 追踪器及配套绑带
- 充电底座与接收器
- 接收器天线
- 一台可运行 SlimeVR 的电脑

::: warning 首次使用前
请先确认追踪器电量充足，并阅读[安全与充电说明](/guide/charging-controls)。
:::

## 1. 连接接收器

1. 将天线正确安装到接收器。
2. 将接收器连接到电脑 USB 接口。
3. 尽量让接收器远离大面积金属遮挡，并保持天线周围空间通畅。

**完成标志：**电脑识别到 USB 设备，启动 SlimeVR 后可以看到接收器或追踪器状态。

## 2. 开启追踪器

### 批量启动

将追踪器正确放入充电底座，按下底座左侧按钮批量开启。

### 独立启动

追踪器处于关机状态时，按下追踪器侧面的功能键即可单独开启。

## 下一步

接收器已连接、追踪器已开启后，继续按顺序完成：

1. **配置 SlimeVR 软件** —— 安装软件、识别设备、分配点位（进入[软件使用](/software/)）
2. **组装与佩戴** —— 胸挂、绑带、佩戴检查
3. **首次校准** —— 完成陀螺仪零偏校准与完整重置

::: tip 批量关机
需要关闭全部追踪器时，在开机状态下按一次接收器左侧的批量关机按钮即可。该按钮以接收器实物丝印为准，避免与追踪器/底座的 `SW0` 混淆。
:::

# 设备校准

校准分为两类：陀螺仪零偏校准通常只在首次使用、固件维护后或明显异常时执行；完整重置与佩戴校准则建议在每次重新佩戴、重启应用后执行。

## 陀螺仪零偏校准

1. 建议连续佩戴约 20 分钟后再校准，以降低温度变化造成的误差。
2. 追踪器保持开机，将全部设备尽快放入充电底座，并将底座放在稳定、水平的表面。
3. 双击充电底座 `SW0` 按键进入校准模式；也可以逐个双击追踪器侧面按键。
4. 从取下追踪器到校准完成建议不超过 1 分钟。校准期间不要触碰或移动追踪器。
5. 指示灯开始闪烁、约 6 秒常亮、再闪烁 3-4 次后，表示校准完成。

## 每次使用前

每次使用前的例行校准（完整重置、身体佩戴校准、脚部校准）与游戏内校准，请按[VRChat 配置](/software/vrchat)中的「每次使用前的准备」操作。

## 校准后仍有偏差

先检查设备是否在运动中松动或移位，再重新执行完整重置和身体佩戴校准。不要通过一次修改多个软件参数来代替校准；仍无法解决时参阅[故障排查](/support/troubleshooting)。

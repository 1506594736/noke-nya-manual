# 充电、按键与安全

## 按键操作

| 设备 | 当前状态 | 操作 | 结果 |
| --- | --- | --- | --- |
| 充电底座 | 追踪器已正确放入 | 按下左侧按钮 | 批量开启追踪器 |
| 追踪器 | 关机 | 按下侧面功能键 | 独立开启追踪器 |
| 接收器 | 追踪器开机 | 按下批量关机按钮 | 批量关闭追踪器 |

原始说明书中，追踪器和充电底座的功能键标记为 `SW0`；接收器左侧金属按键标记为 `SWO`，右侧小孔为 `RST`。

### 追踪器与充电底座 SW0

| 操作 | 功能 |
| --- | --- |
| 短按 1 次 | 重启设备或开机 |
| 快速连按 2 次 | 触发 IMU 校准 |
| 快速连按 3 次 | 重置无线配对 |
| 快速连按 4 至 6 次 | 进入 DFU 固件升级模式 |
| 长按 1 至 5 秒后松开 | 关机 |

### 接收器 SWO

| 操作 | 功能 |
| --- | --- |
| 短按 1 次 | 关闭所有已连接的追踪器 |
| 快速连按 2 次 | 退出配对模式 |
| 快速连按 3 次 | 进入配对模式 |
| 长按至少 5 秒后松开 | 清除所有已配对设备记录 |

::: warning 配对记录
接收器长按会清除所有已配对设备记录。只有在需要重新配对全部设备时才执行此操作。
:::

## 指示灯状态

指示灯可能随固件版本调整，下表为常见状态参考。

| 场景 | 指示灯表现 |
| --- | --- |
| 等待配对（配对模式） | 蓝灯每秒闪烁 1 次 |
| 配对成功 | 追踪器变为绿灯快速闪烁 4 次 |
| 陀螺仪校准（双击 `SW0`） | 绿灯闪烁 1 次，随后常亮约 4-6 秒，最后闪烁 3-4 次表示完成 |
| DFU 固件模式（`RST` 连按 3 次，或 `SW0` 快速连按 4-6 次） | 红灯闪烁 |

配对操作见[新增或更换追踪器](/guide/add-tracker)。

## 设备充电

1. 检查充电底座和追踪器触点是否清洁。
2. 按照正确方向将追踪器放入底座。
3. 使用符合产品铭牌要求的 USB 电源为底座供电。
4. 通过指示灯确认设备是否进入充电状态。

::: danger 出现异常时立即停止使用
如果电池出现鼓胀、破损、异味、异常发热或外壳变形，请停止充电和使用，并联系售后支持。
:::

## 基本安全要求

- 避免跌落、穿刺、挤压和液体进入设备。
- 不要在高温、阳光直射或潮湿环境中充电。
- 不要使用规格不明确或损坏的充电器、线材和底座。
- 长期不使用时，应定期检查设备和电池状态。
- 儿童使用时需要成年人监督。

# 故障排查

按照你看到的现象选择条目。每完成一步都重新检查问题是否消失，不要一次同时修改多个设置。

## 软件找不到追踪器

1. 确认接收器已安装天线并连接电脑 USB 接口。
2. 确认追踪器已经开启且电量充足。
3. 更换电脑上的另一个 USB 接口，避免先经过无供电的扩展坞。
4. 关闭重复运行的 SlimeVR 实例，然后重新启动软件。
5. 检查追踪器与接收器是否仍然配对、固件是否匹配。

## 显示已连接但没有运动

1. 确认对应追踪器没有自动关机或电量耗尽。
2. 将追踪器靠近接收器并减少遮挡。
3. 重新启动追踪器和 SlimeVR。
4. 如果设备仍无反应，记录指示灯状态后联系支持。

## 经常掉线或动作延迟

- 保持接收器天线周围无遮挡。
- 不要把接收器放在电脑机箱背后或紧贴大型金属物。
- 缩短追踪器与接收器之间的距离。
- 尝试直接连接电脑 USB 接口。
- 重启电脑而不是仅关闭后再次开机。

## 身体或脚部方向相反

1. 检查追踪器分配的身体部位是否正确。
2. 检查左右设备是否装反。
3. 检查设备朝向是否与佩戴图一致。
4. 重新执行完整重置和佩戴校准。

## 漂移过快

1. 确认追踪器固定牢固，没有在衣物表面滑动。
2. 重新进行设备校准。
3. 重新执行完整重置和佩戴校准。
4. 远离明显磁场或机械振动干扰。

## 角色不能下蹲或头部高度被固定

1. 确认头显本身在 SteamVR 中可以正常上下移动。
2. 确认 SlimeVR 中没有将追踪器错误分配给头部、左手或右手。
3. 在 SlimeVR 重新执行完整重置和身体佩戴校准。
4. 在 VRChat 中确认真实身高与全身追踪设置，详见[VRChat 配置](/software/vrchat)。

## 腿部抬起、踢腿或弯腰方向不正确

1. 检查大腿追踪器是否固定在膝盖上方正前方，而不是大腿侧面。
2. 检查小腿、脚部和髋部设备是否在动作中发生转动或滑动。
3. 核对 SlimeVR 分配的左右部位是否正确。
4. 重新执行完整重置和身体佩戴校准；已分配脚部追踪器时，再执行脚部佩戴校准。

## 追踪器与模型整体偏移很远

1. 停止动作，确认绑带和胸挂没有移位。
2. 在 SlimeVR 执行完整重置，并保持直立姿势到倒计时结束。
3. 执行身体佩戴校准后，再进入 VRChat 完成游戏内校准。
4. 若只在某个模型发生偏移，重新调整该模型骨架并重新绑定。

## 某个关节被锁住或身体部位自动偏转

1. 检查对应追踪器是否仍在 SlimeVR 中持续更新。
2. 检查该点位的追踪器是否松动、装反或分配错误。
3. 重新启动 SlimeVR 和追踪器，再执行完整重置与佩戴校准。
4. 更换模型后才出现问题时，检查 VRChat 模型骨架和全身追踪节点。

## 无法充电

1. 确认追踪器方向正确并完全接触底座。
2. 清理充电触点表面的灰尘和污物。
3. 更换可靠的 USB 线材和符合产品标注的电源。
4. 出现异常发热、鼓胀或气味时立即停止充电。

## 更新固件后无法连接

确认追踪器和接收器使用相互兼容的固件版本。不要连续尝试不同型号固件，记录更新文件名、工具提示、版本和指示灯状态后联系支持。

## 仍未解决

前往[联系支持](/support/)，按照信息清单准备设备型号、固件版本、系统版本、SlimeVR版本、复现步骤和视频。

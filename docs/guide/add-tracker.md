# 新增或更换追踪器

适用于追加点位、更换单个追踪器，或接收器配对记录被清除后的重新配置。

## 开始前确认

1. 记录当前追踪器、接收器和固件版本。
2. 确认新增设备与现有设备型号、接收器和固件兼容。
3. 先关闭 SlimeVR，保持接收器已安装天线并连接到电脑。
4. 不要在不确定原因时长按接收器 `SWO`；该操作会清除所有已配对设备记录。

## 重新配对

1. 开启需要添加的追踪器，并让它靠近接收器。
2. 让接收器进入配对模式：接收器 `SWO` 快速连按 3 次进入配对模式，快速连按 2 次退出配对模式。
3. 让追踪器进入可配对状态：在需要添加的追踪器或其充电底座上，`SW0` 快速连按 3 次，重置该追踪器的无线配对。
4. 等待配对完成，重新启动 SlimeVR，检查设备是否出现在追踪器列表。
5. 多台设备需要配对时重复以上步骤；不要反复清除接收器的配对记录。

::: tip 配对模式指示灯
配对模式下，接收器与追踪器均为**蓝灯闪烁**提示正在等待配对（追踪器蓝灯为每秒闪烁 1 次）。配对成功后，追踪器指示灯变为**绿灯快速闪烁 4 次**。配对过程中请让追踪器保持靠近接收器。
:::

::: warning 不确定时先联系支持
不同硬件与固件的指示灯状态可能不同。配对失败时，不要反复清除接收器记录；记录当前状态后联系[售后支持](/support/)。
:::

## 完成后必须执行

1. 在 SlimeVR 中将新增设备分配给正确身体部位。
2. 按照[组装与佩戴](/guide/assembly)固定追踪器，确认方向与其他同类点位一致。
3. 完成[设备校准](/device/calibration)中的完整重置和身体佩戴校准。
4. 穿戴头显进入 VRChat 后，按照[VRChat 配置](/software/vrchat)检查模型骨架与追踪器位置。

# SlimeVR 软件使用

本页图片和顺序与原始 WPS 教程一致。第一次使用建议先完成 6 点配置，熟悉佩戴、分配与校准后再增加点位。

## 下载与安装

从 [SlimeVR 官方网站](https://slimevr.dev/) 获取软件。安装前建议关闭正在运行的 SteamVR、VRChat 和其他可能占用相关组件的软件。

::: tip 下载遇到问题
可加入 [NekoNya Slime Tracker 售后 QQ 群](https://qm.qq.com/q/AFd83favza) 获取经过确认的离线安装包。不要使用来源不明的固件或安装程序。
:::

## 首次启动与语言

1. 第一次打开 SlimeVR 后，在欢迎界面右下角打开语言菜单。
2. 选择“简体中文”，然后点击“我同意”。
3. 点击“我准备好了”。接入 2.4G 接收器后，可以按右上角 `ESC` 跳过未完成的向导项目。

## 开启与识别追踪器

1. 将追踪器依次放入充电底座，按一次底座 `SW0` 按键批量开启。
2. 回到 SlimeVR，正常情况下会看到未分配的追踪器。
3. 没有出现设备时，先确认接收器、天线、追踪器电量和开机状态，再参阅[故障排查](/support/troubleshooting)。

## 分配追踪器

1. 在追踪器分配界面选择实际购买的点位数量；6 点建议开启镜像显示。
2. 从默认 5 点切换到 6 点时，骨架会出现髋部点位。
3. 点击骨架白色圆点或部位名称，再从已连接的追踪器列表中选择设备。
4. 不确定某个设备时，轻微摇晃它；对应设备会出现紫色光晕。也可以按界面提示轻敲设备两次。
5. 不要把追踪器分配给头部、左手或右手，这些位置由头显和控制器负责。

## 推荐软件设置

1. 点击左下角“设置”，进入 SlimeVR 设置页后滚动到底部。
2. 关闭“开启敲击重置航向轴”。
3. 进入“追踪器设置”，将预测模式改为平滑型；滤波强度可从 40% 至 50% 开始尝试。
4. 进入“行为”，开启开发者模式和“显示更多信息”。
5. 回到主界面，切换为列表视图，便于查看设备电量、版本和连接状态。

## 每次使用前

确认追踪器电量充足、接收器周围无遮挡、设备已分配到正确部位。重新佩戴后执行完整重置与佩戴校准，具体见[设备校准](/device/calibration)。

## 成功状态

<span class="state-ok">正常：</span>软件显示预期数量的追踪器，移动设备时界面中的追踪器同步运动。

<span class="state-check">需要检查：</span>显示已连接但没有运动、数量不完整、方向相反或很快发生明显漂移。
